# Lupix

A bitmap font, Lupix, available in multiple formats, plus an experimental smooth/vector variant.
It was built prioritizing a more condensed look, most letters were drawn using 6 pixels of width, except by M, V, X, W, m, v, w which occupies 7 pixels.

## Formats

- **Lupix.ttf** — TrueType version of the bitmap font, built from the BDF file using BitsNPicas 
- **Lupix.bdf** — Bitmap Distribution Format
- **Lupix.psf** — PC Screen Font 
- **Lupix-Smooth.ttf** — Experimental non-bitmap variant, built to visually match Lupix while being a smooth outline fon

## Notes

Lupix-Smooth is experimental — it's a reinterpretation of Lupix's look in vector form rather than a direct conversion, so minor differences from the bitmap original are expected.
